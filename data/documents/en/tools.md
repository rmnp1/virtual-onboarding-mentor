# Company Tools

## Communication
- **Slack** — main team communication. Channels: #general, #engineering, #product, #random
- **Google Meet** — video meetings. Links are in Google Calendar
- **Email** — formal communication, client messages

## Project Management
- **Jira** — task and sprint tracking. Every task has a ticket number and description
- **Confluence** — project documentation and team knowledge
- **GitHub** — code repositories, pull requests, code review

## Development
- **GitHub Copilot** — coding assistant
- **Internal Wiki** — internal knowledge about processes and standards
- **Udemy Business** — online courses for learning

## Security
- **1Password** — company password manager. Use it instead of notes
- **VPN** — required for remote work. Instructions at IT helpdesk
- **MFA** — two-factor authentication is mandatory on all accounts

## Slack — Important Channels for New Employees
- **#onboarding** — new employee questions
- **#help-it** — reporting technical issues
- **#announcements** — important company announcements
- **#watercooler** — casual conversations
